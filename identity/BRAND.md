# Svgforge: brand

## Name

**Svgforge.** A forge shapes metal under fixed heat with fixed dies, and the same die gives the same part every
time. Svgforge does that for figures: a Python spec goes in and a self-contained SVG comes out, identical on every
run. The name carries the format (SVG) and the promise (made, not drawn).

## Tagline

> **Every figure is a function. Same spec, same picture.**

## The symbol in the work

| Brand element            | What it maps to in the work                                   |
| ------------------------ | ------------------------------------------------------------- |
| The die                  | The spec: the one source of a figure.                         |
| The same part every time | Byte-identical output, proved three builds in a row and in CI. |
| Quenching                | The lint gates: a part that fails is not used.                |
| The smith's eye          | Reading the PNG before a figure is called done.               |

## Look

Light paper (`#fbfaf7`), dark ink (`#1c1b18`), one blue accent (`#2f5d8a`) and one sans family (Instrument Sans).
Teal, rose and violet appear only where meaning needs a second hue.

## One line

Svgforge turns a short spec into a diagram that agents can draw, read and keep current.
