# Figures

Rendered by svgforge from Python specs. Each SVG is self-contained. Its full description is the `alt` in `INDEX.json`, and the same text is in the SVG's `<desc>` and `aria-label`, so an agent can read the figure without looking at it.

```bash
svgforge build src/svgforge/examples --out examples
```
